# UE18sales — 북페어 판매 현황

한 페이지짜리 판매 집계표입니다. 빌드 없이 `index.html` 하나로 동작합니다.

- 탭: **11/6 · 11/7 · 11/8 · 총합** (총합은 세 날짜를 더한 값, 수정 불가·날짜별 수량 표시)
- 작품 | 작가 | 가격 | + / − | 수량 | 금액 을 한 줄씩 표시, 맨 아래에 합계 (총 ○개 · 총 금액)
- 우측 상단 한 / 中 버튼으로 한국어·중국어 전환
- 수량은 그 기기 브라우저에 자동 저장 (새로고침해도 유지). 판매일 당일에 열면 그 날짜 탭이 먼저 열림
- `초기화` : 지금 보고 있는 날짜의 수량만 0으로 / `CSV 저장` : 날짜별 수량과 총합을 엑셀용 파일로 내보내기
- 작품·가격을 바꾸려면 `index.html` 안의 `WORKS` 목록을 수정

디자인은 작품 소개 사이트(SYDesign)와 같은 톤(라이트그레이 배경, 블랙 글자, Noto Sans KR)입니다.
